## Como utilizar

1. Escolha o comando desejado.
2. Copie o texto do quadro.
3. Substitua as informações entre colchetes.
4. Cole na sua ferramenta de IA (ChatGPT ou Gemini).
5. Revise o resultado antes de publicar.

> **25 comandos prontos** para utilizar no ChatGPT ou no Gemini, organizados em cinco categorias: estratégia de conteúdo, legendas, Stories, Reels e campanhas.

## Categoria 01 — Estratégia de conteúdo

### Comando 01 — Planejador de marketing

```prompt
Atue como estrategista de marketing especializado em negócios de beleza.
Meu negócio é [TIPO DE ESTABELECIMENTO], localizado em [CIDADE].
Meus principais serviços são [SERVIÇOS].
Meu público é [PÚBLICO].
Crie um planejamento de marketing para os próximos 30 dias, incluindo ideias de publicações, Stories, vídeos curtos, campanhas e ações para estimular agendamentos.
Organize o planejamento por semana e explique o objetivo comercial de cada ação.
```

### Comando 02 — Identificação de público

```prompt
Atue como especialista em marketing para o setor de beleza.
Analise meu negócio: [DESCRIÇÃO DO NEGÓCIO].
Identifique três perfis de clientes que podem ter interesse nos meus serviços.
Para cada perfil, apresente necessidades, desejos, dúvidas frequentes, objeções de compra e tipos de conteúdo que podem despertar interesse.
Não presuma características que não possam ser justificadas pelas informações fornecidas.
```

### Comando 03 — Diferenciação da concorrência

```prompt
Ajude-me a posicionar meu negócio de beleza de maneira diferenciada.
Meu estabelecimento oferece [SERVIÇOS] e possui os seguintes diferenciais: [DIFERENCIAIS].
Apresente cinco possibilidades de posicionamento, com exemplos de mensagens que posso utilizar no Instagram e no WhatsApp.
Não invente diferenciais. Trabalhe somente com as informações fornecidas.
```

### Comando 04 — Ideias para redes sociais

```prompt
Gere 30 ideias de conteúdo para o Instagram de um [TIPO DE NEGÓCIO].
Divida as ideias em cinco categorias:
- Educação.
- Entretenimento.
- Bastidores.
- Relacionamento.
- Divulgação comercial.
Para cada ideia, informe o formato recomendado e o objetivo da publicação.
```

### Comando 05 — Calendário semanal

```prompt
Crie um calendário de conteúdo para sete dias para meu negócio de beleza.
Considere os seguintes serviços: [SERVIÇOS].
Para cada dia, sugira uma publicação ou sequência de Stories, com tema, texto principal, formato e chamada para ação.
Evite repetir assuntos.
```

## Categoria 02 — Legendas para Instagram

### Comando 06 — Legenda comercial

```prompt
Crie uma legenda para divulgar o serviço [SERVIÇO].
O público que desejo alcançar é [PÚBLICO].
Utilize uma linguagem profissional, acolhedora e persuasiva.
A legenda deve apresentar o serviço, destacar um benefício real e terminar com um convite para agendamento.
```

### Comando 07 — Legenda educativa

```prompt
Crie uma publicação educativa sobre [ASSUNTO RELACIONADO À BELEZA].
Explique o assunto em linguagem simples, como se estivesse orientando uma cliente durante um atendimento.
Inclua uma introdução interessante, três informações úteis e uma pergunta para estimular comentários.
```

### Comando 08 — Legenda para antes e depois

```prompt
Crie uma legenda para acompanhar uma fotografia de antes e depois de [SERVIÇO].
Destaque o trabalho realizado e explique os cuidados envolvidos.
Utilize uma linguagem elegante e profissional.
Não invente resultados, não prometa que outras pessoas terão o mesmo resultado e não faça afirmações clínicas.
```

### Comando 09 — Legenda de bastidores

```prompt
Crie uma legenda para mostrar os bastidores do meu estabelecimento.
A situação apresentada será: [DESCREVA A CENA].
Quero transmitir profissionalismo, cuidado, organização e proximidade com os clientes.
```

### Comando 10 — Legenda de agenda aberta

```prompt
Crie uma publicação informando que minha agenda está aberta para [PERÍODO].
Serviços disponíveis: [SERVIÇOS].
Utilize uma linguagem convidativa, destaque a possibilidade de reservar horários e finalize com uma chamada para o WhatsApp.
Não crie falsa sensação de escassez.
```

## Categoria 03 — Stories que geram interação

### Comando 11 — Sequência de Stories

```prompt
Crie uma sequência de cinco Stories para divulgar [SERVIÇO].
O primeiro deve despertar curiosidade.
O segundo deve apresentar uma situação ou necessidade do público.
O terceiro deve apresentar o serviço.
O quarto deve esclarecer uma dúvida frequente.
O quinto deve convidar para o agendamento.
Entregue os textos separados por Story e sugira o elemento visual de cada um.
```

### Comando 12 — Enquete para clientes

```prompt
Crie dez ideias de enquetes para o Instagram de um [TIPO DE NEGÓCIO].
As perguntas devem ser simples, interessantes e relacionadas aos hábitos de beleza e cuidados pessoais do público.
Apresente duas alternativas de resposta para cada enquete.
```

### Comando 13 — Caixa de perguntas

```prompt
Crie dez perguntas para utilizar na ferramenta de caixa de perguntas do Instagram.
O objetivo é estimular os seguidores a conversarem sobre [TEMA OU SERVIÇO].
As perguntas devem ser naturais e despertar curiosidade.
```

### Comando 14 — Stories de promoção

```prompt
Crie uma sequência de quatro Stories para divulgar a seguinte promoção:
Serviço: [SERVIÇO].
Preço normal: [PREÇO].
Preço promocional: [PREÇO PROMOCIONAL].
Período: [DATA].
Condições: [CONDIÇÕES].
Apresente a oferta de forma clara, valorizando o serviço e explicando as condições.
```

### Comando 15 — Stories de relacionamento

```prompt
Crie sete ideias de Stories para aproximar meu negócio dos seguidores.
Quero transmitir acolhimento, confiança, profissionalismo e personalidade.
Não utilize ofertas ou descontos. O objetivo é construir relacionamento.
```

## Categoria 04 — Reels e vídeos curtos

### Comando 16 — Roteiro de Reel

```prompt
Crie um roteiro de vídeo para Instagram Reels com duração de aproximadamente 30 segundos.
Tema: [TEMA].
Público: [PÚBLICO].
O vídeo deve conter:
- Uma abertura interessante nos primeiros três segundos.
- Desenvolvimento com informações úteis.
- Encerramento com chamada para ação.
Apresente também o texto que aparecerá na tela e uma sugestão de legenda.
```

### Comando 17 — Vídeo educativo

```prompt
Crie um roteiro de vídeo educativo sobre [ASSUNTO].
O vídeo será gravado por um profissional de beleza.
Utilize linguagem simples, natural e profissional.
O roteiro deve ter duração de até 45 segundos e explicar três pontos importantes sobre o assunto.
```

### Comando 18 — Vídeo de apresentação

```prompt
Crie um roteiro de apresentação do meu estabelecimento.
Nome: [NOME].
Especialidade: [ESPECIALIDADE].
Serviços: [SERVIÇOS].
Diferenciais: [DIFERENCIAIS].
O vídeo deve transmitir confiança, proximidade e profissionalismo, com duração de até 40 segundos.
```

### Comando 19 — Vídeo de bastidores

```prompt
Crie um roteiro de Reel mostrando os bastidores de um atendimento de [SERVIÇO].
Sugira cenas, textos curtos para a tela, sequência de gravação e legenda.
O objetivo é mostrar os cuidados e a experiência oferecida pelo estabelecimento.
```

### Comando 20 — Transformar dúvidas em vídeos

```prompt
Liste 15 dúvidas que clientes costumam ter antes de contratar [SERVIÇO].
Transforme cada dúvida em uma ideia de vídeo curto.
Para cada uma, apresente uma frase inicial, uma resposta resumida e uma chamada para interação.
Não invente orientações técnicas. Sinalize quando a resposta depender de avaliação profissional.
```

## Categoria 05 — Campanhas e divulgação

### Comando 21 — Campanha de divulgação

```prompt
Crie uma campanha de divulgação para meu negócio de beleza.
Serviços: [SERVIÇOS].
Público: [PÚBLICO].
Objetivo: [OBJETIVO].
Apresente um conceito criativo, uma frase principal, três publicações para Instagram e cinco mensagens para Stories.
```

### Comando 22 — Campanha para dias de menor movimento

```prompt
Meu estabelecimento costuma ter menor movimento em [DIAS DA SEMANA].
Crie cinco estratégias comerciais para estimular agendamentos nesses períodos.
Considere ações de relacionamento, divulgação, combos e benefícios promocionais.
Apresente vantagens e possíveis riscos de cada estratégia.
```

### Comando 23 — Campanha de indicação

```prompt
Crie uma campanha de indicação de clientes para meu estabelecimento.
Serviços: [SERVIÇOS].
Benefício oferecido: [BENEFÍCIO].
Explique como comunicar a campanha, quais regras devem ser estabelecidas e como divulgar no Instagram e WhatsApp.
Não crie regras que impliquem condições ocultas.
```

### Comando 24 — Campanha de aniversário

```prompt
Crie uma campanha de aniversário para meu estabelecimento.
A data será [DATA].
Prepare um plano de divulgação com sete dias de antecedência, incluindo publicações, Stories, mensagens de WhatsApp e uma oferta especial.
```

### Comando 25 — Análise de publicação

```prompt
Atue como especialista em marketing digital para negócios de beleza.
Analise o seguinte conteúdo:
[COLE A PUBLICAÇÃO]
Avalie:
1. Clareza da mensagem.
2. Capacidade de despertar interesse.
3. Adequação ao público.
4. Qualidade da chamada para ação.
5. Potencial de estimular agendamentos.
Dê uma nota de zero a dez e apresente uma versão melhorada.
```

## Desafio prático

Escolha três comandos desta biblioteca e utilize-os ainda hoje. Nossa recomendação:

1. **Comando 01** para organizar os próximos 30 dias.
2. **Comando 11** para produzir Stories.
3. **Comando 16** para criar um Reel.

O objetivo é transformar os comandos em ações reais de marketing.
